XR Heritage Framework

Developed through doctoral research at the School of Arts, Universidade Católica Portuguesa (UCP Porto) by Manuel Silva, supervised by Prof. Luís Teixeira. This studio connects curatorial and artistic mediation with real-time XR scene production.

01 Co-design with the AI prompt

Copy the master prompt into ChatGPT, Claude, or Gemini. The system asks for your role first to adapt its vocabulary, protect authorial boundaries, and structure your exhibition specification.

View on GitHub

02 Review spatial maquettes and export PDF

Paste the generated JSON into the sidebar. Inspect the gallery elevation, test the interactive viewport pins, attach reference renders, and save a print-ready PDF dossier.

03 Hand off to production or build in Unity

Export the JSON specification for your technical team, or follow the three-step wizard in Unity to generate the playable scene without writing code.

UPM Install Unity package

Add via Git URL in Unity Package Manager (Unity 2021.3 LTS or newer):

CLI Modular AI skills

Four modular skill definitions are available in AI_Skills/ for agentic workflows: intake profiling, multi-perspective mediation, affordance matchmaking, and TAM evaluation.

SDK Automated scene and prefab wizard

Open Tools > XR Heritage Framework > Experience Setup Wizard in Unity to install AR Foundation or OpenXR, instantiate 3D hotspot anchors, and wire the TAM survey logger.

UCP Doctoral research foundation

Developed at the School of Arts, Portuguese Catholic University (UCP Porto). Built on an empirical benchmark of 80+ worldwide museum XR projects (2005–2024) and evaluated by curators, artists, and technologists.

TAM Technology Acceptance Model evaluation

Embeds in-situ visitor micro-surveys measuring Perceived Usefulness (PU), Perceived Ease of Use (PEOU), Curatorial Respect (CR), and Artist Autonomy Preservation (AAP).
